# GitHub Pages

공개 데모: https://jino-222.github.io/Accessible_Wayfinding/

현재 GitHub Actions 배포가 활성화되어 있습니다. 웹 변경 후 Actions → Publish web demo → Run workflow에서 main을 선택하면 재배포합니다.
새 저장소로 옮길 때에는 소유자가 Settings → Pages → Build and deployment → Source를 GitHub Actions로 설정해야 합니다.

웹 실행에는 인증키·계정·카메라 권한이 필요하지 않습니다. 정적 파일만 게시합니다.
