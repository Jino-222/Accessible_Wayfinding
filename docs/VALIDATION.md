실패를 포함한 한 촬영 세션의 validation 450장을 재사용한 비교입니다. 독립된 새 시험집합의 성능이나 도착 성공률이 아닙니다.

별도 test 67장은 정답이 없어 정확도 미채점입니다. 품질 통과 49/67을 정확도로 해석하지 않습니다. 세 관측 재확인·3 m 동선 범위·2 m 접근 범위는 연구용 규칙이며 현장 안전 기준이 아닙니다.

근거: `evidence/evaluation-predictions.jsonl`, `evidence/evaluation-summary.json`, `evidence/test/`, `../web/gangnam/data/research-summary.json`.

## 웹 조작

브라우저에서 이동·도착·끊김 중 이동·복구·접근 중단·재개·탭 전환·기록 저장을 확인했습니다. 360·390·430 CSS px 화면 폭의 조작부와 가로 넘침도 검수했습니다. 근거: `evidence/gangnam-explorer-browser.json`.

직접 이동은 가상 카메라 좌표를 이용한 모의 관측입니다. `3/3`은 새 관측 수신 횟수이며 영상 인식 성공 횟수나 신뢰도 점수가 아닙니다. 실제 촬영 RGB·합성 RGB의 위치 추정 결과는 다른 화면에서 제공합니다.

## 검증하지 않은 항목
